## 3. Clean-Room Implementation Boundaries

1. **Zero Prompt Copying**: QuantLab writes its own structured valuation and checklist prompts rooted in Indian equity accounting conventions (Ind AS, SEBI Clause 41 disclosures, MCA filings).
2. **Zero Code Duplication**: All multi-agent review classes, PIT context filters, and evidence aggregation schemas are written natively in `quant-service/app/ai_research/`.
3. **Primary Truth Isolation**: Financial data, quarterly filings, balance sheets, and cash flow statements are sourced exclusively from QuantLab's canonical PostgreSQL warehouse, never from ungrounded LLM hallucinations.
4. **Deterministic Fallback Guarantee**: If an external LLM API is unavailable, the research engine falls back to a 100% deterministic rule-based evaluation of the 20-point investment checklist and financial ratios.
